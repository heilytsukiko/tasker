# Ассеты

Файлы подхватываются по имени (расширение любое: png, jpg, webp, svg), см. `src/shared/lib/assets.ts`.

| Имя файла | Где используется | Что экспортировать из Figma (лендинг, фрейм 67:44) |
| --- | --- | --- |
| `logo-mark` | шапка, знак логотипа 32×32 | группа `logo` (97:24), только знак без текста «Tasker», SVG |
| `hero-coffee` | фото в карточке hero | слой `image 1` (83:3), исходное фото целиком, PNG/JPG |
| `hero-company-avatar` | аватар «Coffee boom» 48×48 | слой `Vector` (67:82), PNG @2x |

Положите файлы прямо в эту папку (`src/assets/`).
